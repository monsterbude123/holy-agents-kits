# note.md 图文笔记格式

note.md 是「图文配对」的原始素材：屏幕上有什么（帧）+ 讲者说了什么（转写要点），按视频章节编排。它是学习包的上游——学习包只做提炼加工，不重复贴帧。

## 骨架（始终用这个结构）

```markdown
# <视频标题> · 图文笔记

> 来源：<文件名或链接> · 时长 <mm:ss> · 语言
> 一句话总结：<这片子到底在讲什么，一句>

## <章节标题>（<mm:ss>-<mm:ss>）

![<帧内容>](images/<编号>-<内容>.jpg)   <!-- 有信息承载画面才配图 -->

**屏幕**：<画面上有什么：幻灯片要点 / 代码 / 界面操作 / 图表>

**讲点**：
- <口播要点 1，保留讲者给的关键数字与例子>（<mm:ss>）
- <口播要点 2>（<mm:ss>）

> 金句/关键数据：<原话引用或数据，标时间戳>

<!-- ……逐章节重复…… -->

## TL;DR

- <3–5 条，每条独立成立，不依赖上下文>
```

## 写作规则

- 每个要点带时间戳范围，可回溯是底线；没有时间戳的要点不许写。时间戳优先取画面（编号卡 / 烧录字幕逐秒表），转写没有逐句时间戳时不要用「按时间轴提问」反推。
- 配图只配「信息承载帧」（幻灯片、代码、图表、演示界面）；讲者人脸、转场不算。
- 删口误、口癖、重复，但**数字和例子保留原样**，不「顺手修正」——修正属于学习包的事且必须标注。
- 屏幕上的小字（代码/表格/终端输出）以原分辨率读帧读到的原文为准，不凭缩略图猜。
- 无画面信息的段落不硬配图；纯口播视频全篇可以一张图都没有。
- 一章一个主题闭环；讲者「接下来我们讲 X」是章节边界信号，配合转写停顿与镜头边界定位。

## 取帧细则

- **数字类关键帧取动画停稳后 1–2 秒**：标题卡的计数（如 `+46,324`）是滚动动画，早一秒抓到的是中间值（实测 t=9 得 `+45,678`，t=11 才停在真值）。读数前先确认数字两帧一致。
- **两步走取帧**：先按 5–10 秒粒度抽候选帧拼联系表读一遍，定下秒点，再按秒抽原分辨率。Ken-Burns 缩放推进的镜头按秒直接取往往已推到别的内容（完整标题卡在 t=8，t=9 已是放大态）。
- 关键帧落 `images/` 时文件名带序号+内容，序号按片中顺序，方便与章节对齐。
