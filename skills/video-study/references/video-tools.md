# 宿主视频工具对照表

转写、采样、读帧这类机械活复用宿主已有的视频工具，不手搓。按宿主实际装了什么选，从上往下取第一档可用的。

## 首选：video-agent-kit 插件

| 工具 | 用途 | 什么时候用 |
|---|---|---|
| `inspect_media` | 元数据+技术风险（时长/音轨/编码/无音轨告警） | Step 1 第一个动作，结果决定后续分支 |
| `speech_transcribe` | 云 ASR 转写，长媒体自动分块再回贴时间轴 | 拿全文转写；`language` 按视频语言传（中文传 zh）；转写 json 落盘留档 |
| `video_ingest` | 全片联系表采样，可配转写一起返回 | Step 1 摸底章节结构 |
| `video_watch_segment` | 指定时间段高帧率细看，支持多段批量 | Step 2 看动作/动画/演示过程 |
| `video_read_frames` | 原分辨率读帧，可裁剪+放大 | Step 2 读屏幕小字/代码/表格/幻灯片文字 |
| `detect_shots` | 镜头边界检测，出 shots 时间线 | 章节切分拿不准时辅助（边界对齐镜头更自然） |

调用注意：转写优先于看片（先拿全文，采样观察才有对照）；长视频（>1h）先转写再按章节定向细看，不做无目的全片细看；转写无声视频会返回空结果，属正常。

## 备选：video2code 插件

宿主装的是 video2code 而非 video-agent-kit 时等效替代：`ingest_video`（全片摸底）→ `clip_video`（重点段细看）→ `still_crops`（读帧/存关键帧，可用 save_to 直接落产物 assets）。能力足够走完五步，产出不受影响。

## 兜底：宿主自带多模态 / ASR 能力

两个视频插件都没装、但 agent 本身能上传媒体或直接调 ASR 时，就用它转写，别停工。拿到全文后按章节定向看片，流程同上。

**关键限制：这类接口通常只返回「整篇文本 + 段落切分」，没有逐句时间戳。** 不要拿「按时间轴提问」当时间轴用——实测两个模型对同一段落给出的时间相差 5–10 秒且方向相反，片尾还会漂出视频总长（214s 的视频标到 226s）。时间戳一律改由画面取（烧录字幕或画面编号卡），转写文本只负责「说了什么」。

## 时间轴兜底：烧录字幕 → 逐秒表

画面底部有与口播逐句对应的烧录字幕时，这是**最可靠的时间基准**：把字幕带裁出来按 2 秒粒度抽帧、打时间标签、拼联系表，读一遍就得到「秒 → 字幕原文」全表。

```bash
# ① 抽字幕带并打时间标签。W/H 换成实际分辨率：crop 高度约 H*0.2、纵向起点约 H*0.64
#    先抽一张全帧确认字幕下沿；1–2 行字幕且各镜头会漂，裁窄了会切掉半行（实测下沿 875–985px 漂动）
#    FONT 按平台解析后传入：Windows 用 msyh.ttc，macOS 用 PingFang.ttc，Linux 用 fc-match 查；
#    不要把某个平台的绝对路径写死进技能文件（门禁 forbid_windows_paths 也会拦）
ffmpeg -y -i in.mp4 \
  -vf "fps=1/2,crop=W:H*0.2:0:H*0.64,scale=360:-1,drawtext=fontfile=$FONT:text='%{pts\:hms}':x=4:y=2:fontsize=17:fontcolor=yellow:box=1:boxcolor=black@0.85" \
  -q:v 3 out/s%03d.jpg

# ② 拼联系表：输出文件名带 %02d 序号 + -vsync 0，且不要加 -frames:v / -update 1
ffmpeg -y -i out/s%03d.jpg -vf "tile=4x6" -vsync 0 page_%02d.jpg
```

两个坑，各踩一次就够：

- `tile` 配 `-frames:v N` 再配 `-update 1` 会反复覆盖同一个输出文件，**最后只剩最后一页**（107 帧拼 5 页只看到末尾 11 帧）。正确写法就是上面 ②：序号文件名 + `-vsync 0`，不设 `-frames:v`。
- 缺字体文件时 `drawtext` 报 `Fontconfig error: Cannot load default config file`，标签画不出来；按上面对平台解析 `FONT` 再传。

读法：逐页读「秒 → 字幕原文」得到全片逐句表；需要原分辨率时按秒回抽。**章节边界以画面编号卡为准**——`No.N` 标题卡常比口播晚 3–8 秒出现，且角标会延续到该项目所有画面，按语音切会把上一章画面算进下一章。

## 降级：裸 ffmpeg

只想抽帧时（转写由上述任一档提供）：

```bash
ffmpeg -i in.mp4 -vf "fps=1/30" -q:v 3 <视频名>/images/raw/%03d.jpg   # 30 秒一张，按密度需要调
```

**停下来的条件只有一个：既没有 ASR 能力、也没有现成字幕文件。** 有 `.srt`/`.vtt` 时直接解析当转写用（时间轴齐全），不算缺口。

## 落盘约定

- 关键帧（要进笔记的）存产物目录 `images/`，编号+内容命名；观察过程产生的中间帧用临时目录，交付前清掉。
- 转写 json 与镜头时间线存产物目录旁的 `out/` 或临时目录，不混进 `images/`。
- 下载来的视频先落本地再处理；不把网络 URL 直接喂给需要本地路径的工具。
