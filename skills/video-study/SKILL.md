# Video Study — 视频学习加工

输入：一个视频（本地文件或可下载链接）+ 学习者背景（缺就问）。
产出：`<视频名>/` 一个目录 = `note.md`（图文笔记）+ `study/`（结构化学习包）+ `images/`（关键帧）。

## 怎么用

| 用户要什么 | 你做什么 |
|---|---|
| 学习这个视频 / 转成学习包 | 走全流程五步 |
| 只要视频笔记 / 这个视频讲了什么 | 走 Step 1–3，到 note.md 停 |
| 学习包已有，补或改某一块 | 读 [study-package-spec.md](references/study-package-spec.md)，只重做对应模块 |

## 五步主流程

**Step 0 立档** —— 确定视频路径与学习者画像（背景会什么 / 目标学来干什么 / 自认缺口），缺任何一项就问，不猜。画像只决定 Step 4 的**选配**模块；必产三件（README 导航 / 逐主题原理深挖 / 术语速查）不依赖画像，可以先开工——问卷发出去，同时跑 Step 1–3。建 `<视频名>/` 目录（`note.md`、`study/`、`images/`）。机械抽取全走宿主已有视频工具，工具对照表 → [video-tools.md](references/video-tools.md)；既没有 ASR 能力、又没有现成字幕文件时才停下报告（`.srt`/`.vtt` 可直接当转写用），不手搓转写。

**Step 1 摸底** —— 先看元数据（时长/音轨），**开卷先读画面底部的「来源：」标注行**——仓库路径、涨星数、采样口径、图示免责常只写在这里，是免费的一手事实。再转写全文 + 全片采样观察，得到章节结构；一章 = 一个主题完整闭环。时间戳来源按优先级取：① 画面编号卡 / 章节标题卡 ② 烧录字幕（裁字幕带做逐秒表，方法见 video-tools.md）③ 转写自带时间轴；转写只有整段文本时**不要按时间轴提问猜秒数**（实测偏 5–10 秒、片尾还会超出视频总长）。章节边界有 `No.N` 编号卡时以画面为准，口播常早 3–8 秒。按画面形态分叉：纯口播无板书演示 → Step 2 跳过抽帧，笔记按纯时间轴组织；有屏幕内容（幻灯片/代码/图表/演示）→ Step 2 逐段抽帧。

**Step 2 深挖** —— 对每章细看关键段：动作与动画用整段细看，屏幕小字与代码用原分辨率读帧；每章抽 1–3 张关键帧存 `images/`，文件名 = 序号+内容（如 `03-replit-agent-界面.jpg`）。铁律：每条结论都要能落到时间戳或帧上，记不清就回看，禁止凭印象补内容。取帧细则（数字类取动画停稳后 1–2 秒、候选→联系表→原分辨率重抽）→ [note-format.md](references/note-format.md)。

**Step 3 写笔记** —— `note.md` = 图文配对笔记：屏幕内容（引用 images/ 帧）与口播要点（转写）按章节编排，头部元信息+一句话总结，尾部 TL;DR。格式骨架 → [note-format.md](references/note-format.md)。

**Step 4 产学习包** —— `study/` 按画像裁剪模块：必产 README 导航、逐主题原理深挖、术语速查；选配概念迁移表（有旧领域经验）、题库（面试/考核导向）、动手验收标准（实操导向）、前置知识清单（入门导向）。模块决策表与各文件骨架 → [study-package-spec.md](references/study-package-spec.md)。事实来源优先级：画面「来源：」标注行 > 视频正文/画面 > 联网补证（仓库路径先用 GitHub API 核验存在性）。四条纪律：数字必须可溯源到视频原话或画面；需要学习者本人真实经历处用 `[填空]` 占位、不许代填；讲原理讲边界（为什么这样设计、何时失效），不复述 API 用法；不虚构：视频没讲的不混进正文，确需补充的知识明确标「视频外补充」并说明补它的原因。

**Step 5 收尾自检** —— 机械项先跑自检脚本，对 `note.md` + `study/` 查四类硬错（引用帧是否存在 / study 文件是否都被导航 / 讲点是否都带时间戳 / 术语条数与 README 宣称是否一致）：

```bash
python "$HOME/.agents/skills/video-study/scripts/check-output.py" <产物目录>
```

脚本全绿后，再按 [study-package-spec.md](references/study-package-spec.md) 自检清单过它覆盖不到的判断题（无臆测、图文对应、口径一致）。交付时报告产出清单 + 给学习者一条建议使用路径（先读什么后读什么）。

## 分叉与退出

| 情况 | 动作 |
|---|---|
| ASR 不可用、又没有现成字幕文件 | 停，报告缺口；不拿采样帧硬编讲稿内容（宿主自带多模态转写也算 ASR；有 `.srt`/`.vtt` 也不算缺口） |
| 只有音频轨（播客/录音） | 当播客处理：跳过抽帧，笔记按时间轴，学习包照常 |
| 混剪无讲解结构 | 章节按镜头主题聚簇，并向用户明说"本片无连贯讲解" |
| 学习目标没说 | Step 0 必问；不默认任何场景（面试/求职是特例不是通例） |
