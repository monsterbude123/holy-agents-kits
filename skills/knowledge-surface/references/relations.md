# 关联：算得准，且说清来源

关联边是「知识图谱」最容易变成毛线团的地方。原则：**一条边要么有实据（共享同一个概念词），要么明确标成位置关系；不编关键词。**

## 1. 两类词，作用完全不同

| | `terms`（连边用） | `keywords`（展示/搜索用） |
|---|---|---|
| 来源 | 正文里的 `**加粗术语**` | terms + 标题切词 |
| 用途 | 算节点之间的关联 | 搜索命中、tooltip 辅助 |
| 例子 | `**令牌桶**`、`**死信队列**` | `+`标题里的「租约」「退避」 |

**连边只用语料强概念词 `terms`，绝不 fallback 到 `keywords`。** 用标题切词连边的后果实测过：「测试」出现 144 次、「来源说明」126 次——所有节点连成一坨，因为每个文件都有「测试」这个词。

## 2. 结构词要剔（markStructuralTerms）

正文里的加粗词里混着大量「模板词」：每个文件都有的固定小节名、协议词、统计词。这些词一参与连边，图立刻退化。

三类剔除规则（`markStructuralTerms(nodes, {soloRatio=0.6, hotRatio=0.2, spreadRatio=0.5, minDf=3})`）：

1. **协议词（spreadRatio）**：出现在 > 50% 文件里的词 → 必然是模板，不是概念。
2. **高频词（hotRatio）**：节点 df > 20% 叶节点数的词 → 泛用词，连边无信息量。
3. **模板小节名（soloRatio）**：df ≥ 3 且「行首加粗 + 冒号」形式出现占比 ≥ 0.6 → 是小节标题的写法，不是术语。
   判定「标签式出现」用 `pickSoloTerms()`：`^\s*\*\*([^*\n]{2,14})\*\*\s*(?:[:：]|$)`。

实测剔除示例：实测结果 / 进阶思考 / 测试 / 来源说明 / 逐字稿 / 节奏 / 综合分 / 五条规则 / 补充要点。
实测保留示例：框架错位 / 守恒式 / 语义缓存 / 滑动窗口裁剪 / 削峰填谷 / 死信队列。

**术语合格线**（`termOk`）：长度 2–14、非纯数字、非 `A1` 式编号、不含句末标点。`cleanTerm()` 剥掉包裹引号（`**"测试"**` → `测试`）。

剔除结果写进产物的 `templateLabels` 字段，方便人工复核剔得对不对。

## 3. 计分

```
score(a, b) = |terms(a) ∩ terms(b)|            // 实关联
            + 0.5 · 同组                          // 位置关系
            + 0.5 · 同文件                        // 位置关系
```

只有 `terms` 交集非空才建边；位置关系**只做加权，不单独建边**。

## 4. 兜底边要标明

实在没有共享概念的叶节点（早期章节、孤立卡片），挂到**同文件的相邻节点**上，并标 `basis: 'sibling'`。UI 上这类边要画成弱化样式，tooltip 里写「同文件相邻」——不要让它看起来像一个真实的知识关联。

> 位置关系的边不是知识边。它只保证「这个节点不是孤儿」，让图连成整体。

## 5. 数量上限

每个叶节点最多 `--max-links` 条边（默认 6），按分数取前 N。同一个节点对不重复建边。

上限是给「可读」服务的：叶节点连 20 条边，图就变成毛线球，而这道边带来的信息量远低于被挤掉的 19 条。

## 6. 同名节点：关联条目必须带上下文

语料里经常出现同名标题（不同文件都叫「1.1 机制全链路」，或同一文件里两个小节同名）。此时关联条目只显示标题，用户分不清跳到哪一个，会以为系统连到了自己。

修法（viewer 侧，通用）：建一次 `titleCount`（标题 → 出现次数）；某个目标标题在语料里不唯一时，关联条目补一段上下文：

```
<chip>1.1 机制全链路 · Part 1 · Function Calling 完整机制 · 同文件相邻</chip>
             ↑ 父级小节名（parentId → 父节点标题），父节点缺失时退化为文件名
```

树上的位置本身能区分同名节点，不用改；只有「跳转型」的关联条目需要。

## 7. 质量判据（人工看一眼）

建完边看 top 共享词：

- **好**：前 15 个共享词全是真概念（框架错位 / 守恒式 / 滑动窗口裁剪 / 超卖有上界 / 削峰填谷 / 语义缓存 / 单一事实源 / 模型路由 / 三级优先级 / 死信队列）。
- **坏**：前 15 出现「测试」「说明」「总结」「方法」「问题」这类泛用词 → 规则没剔干净，回看 §2。

再看两件事：

1. **有没有本该连没连的**：同一概念在两个文件里各出现一次、但没连上 → 术语抽取漏了（比如那个词没有加粗）。
2. **有没有不该连的**：两个无关卡片因为共享一个泛用词连上 → 同上。

## 8. 边界

关联是**呈现层的辅助**，不是检索系统。要「按关键词全文检索、按行号跳转」，交给文档索引类技能；本技能的关联只服务于「这张图里的两个点为什么挨在一起」。
