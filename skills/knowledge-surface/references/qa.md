# 交付前逐条过

每条都有**判据**，不靠「看着还行」。勾不上就回去改，别在交付说明里写「可能有点问题」。

## A. 构建层（脚本跑完就有结论）

| # | 检查 | 判据 |
|---|---|---|
| A1 | 构建成功 | stderr 第一行 `[ok] N 文件 / N 组 / N 叶节点` |
| A2 | **没有摘要的叶节点 = 0** | 没有 `[warn] N 个叶节点没有摘要` |
| A3 | **孤儿节点 = 0** | 没有 `[warn] 孤儿节点 N 个` |
| A4 | 关联数量合理 | 「N 个有关联」不是 0，也不是 90%（90% 说明边没有信息量） |
| A5 | 单文件自包含 | `--echarts` 给了本地文件 → 断网双击也能开 |
| A6 | 产物无路径泄漏 | HTML 里搜不到构建机的绝对路径（除 data 字段） |

## B. 全图（打开产物第一件事）

1. **默认视图 = 骨架**：根 → 组 → 文件，一屏能看完；不是几百个叶子糊成一片。
2. **全展开也不炸**：点「展开全部」，节点不重叠、不出 NaN 坐标、不白屏。
3. **标签自动降级**：节点多时叶标签消失，文件标签仍在且可读。
4. **规模数字可读**：顶栏的文件/组/叶节点/关联数对得上 JSON。
5. **分组色可辨**：相邻两组颜色不撞；「其它」组是灰色。
6. **图例不挡内容**：右上竖排，不压节点。

## C. 披露

1. **hover 出摘要**：一句话 + 文件名；没有摘要的节点明说「（无摘要）」。
2. **点叶节点出明细**：标题 + 一句话 + 正文（md 渲染结构完整：标题/列表/引用/代码）。
3. **长文能滚**：面板不撑破视口。
4. **Esc 关闭 / 点空白关闭**，关掉无残影。
5. **点非叶节点 = 展开/收起**，不是出明细（两种语义不能混）。
6. **展开态跨重建保留**：点开 → 触发一次重渲染 → 展开态还在。

## D. 搜索

1. 搜索命中**看得见**（不是命中了却被密度规则藏掉）。
2. **命中路径自动展开**（祖先链展开到命中项）。
3. 命中高亮（金色 + 700 字重），非命中降到 opacity .35。
4. 顶栏显示命中数。
5. **根节点永远展开** —— 搜索态把根收起 = 整图消失（坑 13）。

## E. 性能（语料规模 × 交互）

| 规模 | 期望 |
|---|---|
| < 300 节点 | 首屏 < 1s，交互 60fps |
| 300–800 节点 | 首屏 < 2s；展开动画不卡死 |
| > 800 节点 | **拆多张 surface**（按组），不要硬塞一张画布 |

自检：展开全部后持续漫游/缩放，浏览器不崩、不掉帧到不可用。

## F. 交付（按消费方写，不写过程）

1. **交付物 → 消费方对照表**：产物是什么、谁打开、怎么用（双击 / 命令行）。
2. **启动指令**：可直接复制的一行命令 + 打开地址。
3. **已知限制**：如实写（哪些没接线、哪些边界没覆盖），不要藏。
4. **不写**：内部路径、决策编号、日期时点、过程文档引用、未决清单。
5. **不写没用的按钮**：外部数据接口没接线的，别留一个点了没反应的入口。
