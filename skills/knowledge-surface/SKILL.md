# 知识表面 · 一眼全图的披露式可视化

把「一摞 Markdown」变成一个**能一眼看完、并且能逐层钻进去**的界面。

核心范式四步，缺一步就退化成「把 md 渲染成大号列表」：

| 步 | 做什么 | 判据 |
|---|---|---|
| 1 结构化 | 文档 → 节点树 | 标题层级即结构；容器节点带分组色，叶节点带一句话摘要 |
| 2 图型化 | 节点 → 图形 | canvas 树 / 力导向，不是列表、不是表格、不是目录页 |
| 3 一眼全图 | 全貌进一次视野 | 全展开时节点不重叠、标签自动降级、规模数字可读 |
| 4 披露式明细 | 概览 → 摘要 → 全文 三级 | hover 出一句话，点开出全文，Esc 关闭，明细可滚动 |

审美不是装饰：配色、字号梯度、对比度、密度策略是「一眼全图」能否成立的前提 → `references/disclosure-and-style.md`。

**边界**：只管「结构 → 图 → 披露」的呈现范式。不产出内容、不做检索索引与文档地图（agent 检索走 `doc-map-manager`）、不判分与出题、不做文档治理（`human-docs`）、不写学习材料。

## §1 骨架流程

1. **盘结构** —— 数一下语料：几个文件、标题几级、什么算叶节点、分组怎么切 → 落一份 `surface.config.json`（分组映射 / 摘要段 / 叶节点正则）。语料若已有既定分组（人工校定的领域划分），照抄不重造。
2. **解析** —— `node scripts/build_surface.mjs --in <语料目录> --out <产物>.html` → 出单文件界面（内嵌数据，双击可开）。自检：节点数合理、叶节点摘要非空、孤儿节点为 0。
3. **全图体检** —— 打开产物第一件事是**全展开**：节点平铺无重叠？标签密度自动降级了？分组色可辨？规模数字可读？不合格先调分组/配色/密度阈值，别急着加功能。
4. **披露体检** —— hover 出摘要？点开出全文？Esc 关闭？长文能滚？关联节点可点跳转？明细排版（标题/引用/列表/代码）读得下去？
5. **接外部数据** —— 明细需要外部内容（深挖层、音频、进度接口）时，在 viewer 里接 `/api/*`；写清「谁消费、是否已接线」，未接线就别留按钮。
6. **交付** —— 交付物→消费方对照表 + 启动指令 + 已知限制（不写过程产物、不写内部路径）。

## §2 核心逻辑

- **结构默认取标题层级** —— md 的 H1→H4 天然是树；「卡片」写法（`### 卡 1 · 标题`）本来就是 H3，不用另写解析器。只有当标记出现在正文而非标题时，才用 `--leaf-pattern` 正则。
- **分组不靠猜** —— 默认按目录切；目录拍平时写 `config.groups`（正则匹配文件名 → 域）。人工校准过的分组信息比自动聚类可信。
- **叶节点要有摘要** —— 摘要缺失 = 界面退化成目录。取 designated 段，没有就取正文第一段实质内容（跳过纯标签行、表格行、代码块），**在句边界截断**。
- **关联要诚实** —— 关键词交集是实关联；同组/相邻只是位置关系，UI 上必须标成「同组」而不是编一个关键词。详见 `references/relations.md`。
- **规模超限要拆** —— 单元 > 800 或全展开标签必然重叠时，按组切成多个 surface，而不是硬塞一张画布。
- **要精确行号就别建图** —— 读者要「跳到第 N 行」时，图不如索引；这类需求交给文档索引类技能。

## §3 核心循环

```
盘结构 → 解析 → 全图体检 → 披露体检 → (不合格) 回解析 / 调阈值
                    └──── 全通过 → 接数据 → 交付
```

**退出条件**：全展开一屏可读（无重叠、无 NaN 坐标）+ 叶节点摘要非空 + 搜索能定位 + 明细三段齐全（标题/摘要/正文）+ 关联边有来源标注。

## §4 脚本

```bash
node scripts/build_surface.mjs --help          # 参数与用法
node scripts/build_surface.mjs --in ./docs --out ./surface.html \
     --config ./docs/surface.config.json --echarts ./vendor/echarts.min.js
```

产出单文件 HTML（数据内嵌，双击即开）；`--echarts` 给本地文件则离线自包含，不给则走 CDN 并在页面上给出失败提示。

## §5 参考文件

- `references/parsing.md` —— 盘结构与写 `surface.config.json` 时读：分组映射、摘要段、叶节点正则、摘要截断规则
- `references/relations.md` —— 调关联质量或解释边来源时读：关键词抽取、加权计分、honesty 约束
- `references/rendering.md` —— 画布不听话时读：ECharts 配方 + **必须避开的坑清单**（状态残留、展开态归属、坐标 NaN、密度阈值）
- `references/disclosure-and-style.md` —— 做明细排版或调观感时读：三级披露、色板、字号梯度、密度策略
- `references/qa.md` —— 交付前逐条过：全图、披露、搜索、性能、自检
