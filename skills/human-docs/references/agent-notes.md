# agent 侧:防遗忘的手记形态

给下一个上下文的 agent 看的手记,不是给人读的。目标是**结构化防遗忘**,不是篇幅。

四件套:DAG 任务表、分层索引地图、临时 todos、时效分层(冻结 / 活跃 / 临时)。

## DAG 任务表(任务 = 节点,依赖 = 边)

| 任务 | 依赖 | 状态 |
|---|---|---|
| T1 取材 | — | done |
| T2 加工 | T1 | doing |
| T3 汇总 | T2 | todo |

依赖列必须可机读(任务号或 `-->` 边);无依赖写 `—`;状态只有 todo / doing / done 三态;出现环 = 任务拆错了,拆到无环为止。这就是 agent 版的脑图:人看树,agent 看拓扑序。

## 分层分级索引地图(按需下钻的入口)

- L0 一句话:这个东西是什么,现在什么状态
  - L1 能力域 / 目录:一行一个,只写名字与一句话
    - L2 明细(文件 / 符号 / 参数):只在下钻时展开,平时不驻留上下文

索引地图是 agent 的「周围环境感知」:常驻上下文的只有 L0–L1,L2 用完即走——上下文是工作记忆,不是仓库。

## 临时 todos(会话级,不落长期文件)

策划中的 todos 只活在当前会话/当前任务里:写在对话里或会话级暂存区,**不写进任何长期文档**。会话结束即失效——策划是过程,不是事实;过程产物进了长期文档,就成了给后续 agent 的过期指令。

## 时效分层:冻结 / 活跃 / 临时(仿生人类记忆)

| 层 | 类比 | 允许的变化 | 归宿 |
|---|---|---|---|
| 冻结知识 | 长期记忆 | 只读;要改 = 追加修订记录,不原地改写 | 长期文档 / 正式工件 |
| 活跃文档 | 工作记忆 | 可随时改写 | 任务期间存在,任务结束转冻结或废弃 |
| 临时产物 | 短暂印象 | 任意 | **用完即焚** |

**焚毁协议**:会话 / 任务收尾时,清点本轮产生的临时产物(草稿、中间清单、一次性笔记)——已固化进活跃文档或冻结层的,原稿焚毁;未固化的,要么当场固化要么当场丢弃,不留「以后再说」。判据:一个临时文件如果活过了一个任务,它要么升级为活跃文档,要么就是噪音——没有第三种状态。噪音的代价由下一个上下文的 agent 支付:它会把过期产物当成事实。
