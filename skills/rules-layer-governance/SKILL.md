# rules-layer-governance

> **边界一句话**：只治「规则文件」本身的立法与瘦身（AGENTS.md / SKILL.md / 目录章程）；代码规范怎么写归项目 skill，经验记账归经验账本类技能。

## 何时用

- 规则文件膨胀、上下文击穿，要做预算瘦身
- 要给存量规则补来源（出处制）、判归宿（单一归宿）
- 要把「靠自觉遵守」的 prose 规则变成机器门禁（可脚本验证的那些）
- 要独立复核别人（或子代理）做的规则层改动

## 6 步流程

| 步 | 动作 | 产物 | 卡点 |
| --- | --- | --- | --- |
| 1 | 盘点：列全规则文件 + 行数基线 | inventory | 冻结基线，之后只对比不重估 |
| 2 | 立法：三要素成文（预算 / 出处制 / 单一归宿 + 提议权） | 规则层治理节 ≤15 行 | **须人批准后才算生效**，agent 不得自定 |
| 3 | 模板化：套 `- 规则 \| 出处: X \| 候选下沉: 可/否` | 逐文件转换 | 只改格式，禁增删语义 |
| 4 | 下沉：可脚本验证的规则 → `scripts/gates/<编号>.sh` | 门禁脚本 + README 索引 | 删正文留一行指针，**编号不动** |
| 5 | 复核：三向语义保真 + 门禁回归 + 死引用扫描 | 复核报告 | 不采信执行方自检 |
| 6 | 记账：踩坑写账本，方法沉淀回本 skill | LEARNINGS 条目 | 记了要闭环 = 变成某条规则/脚本的改动 |

## 5 条铁律（每条都带验证方法）

1. **只改格式、禁增删语义** —— 改前改后的「规则文本单元集合」必须逐字相等，用 `references/verification.md` 的三向校验器跑。
2. **存量的出处写「存量-未溯源」，不许编造** —— 编造来源会被校验器判为杜撰，零容忍；「查不到来源」本身就是合法出处。
3. **新旧格式永久互斥时必须接替改写并向人披露** —— 两套格式并存 = 规则自相矛盾（例：旧「YYYY-MM-DD · 来源」vs 新「出处:」字段）。
4. **下沉只删正文的一半** —— 删正文、留一行指针、编号不动；下游 skill 普遍按「§二 #N」按编号引用。
5. **基线只能实测，不能手测** —— 含 `$&` / `!$` / 反引号的命令经多层 shell 引号会被二次展开篡改（实测假值 647 vs 真值 618），基线必须在脚本文件内测。

## 详见

- `references/legislation-protocol.md` —— 三要素立法细则 + **什么算 prose 规则的口径裁定表** + 预算超标与双阈值冲突处置
- `references/gate-authoring.md` —— 什么该下沉 / 不该下沉、脚本骨架、ratchet vs 判定型、EXCEPTIONS 协议、自测协议、已踩过的 4 个坑
- `references/verification.md` —— 三向语义保真校验器、门禁回归、死引用扫描、人工定性纪律
- `templates/gate-script.sh` —— 可直接 `cp` 的门禁骨架
- `templates/check-dead-refs.sh` —— 规则文件死引用扫描器（泛化版，含 `--selftest`）

## 失败模式速查

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 剥离括注后留下 `**）**` / `）。` | 尾部字符没被一并剥掉 | 扫 `\*\*）\|）。` 形态，补 Edit |
| 基线值与真实计数差一大截 | 多层引号把 `$&`/`!$` 展开了 | 基线改在脚本文件内测 |
| 门禁自测被安全护栏拦下 | 命令里出现敏感文件名 | 用 mock `git` 桩伪造输出，样例用完即删 |
| Edit 改完变量为空 | 替换文本里的换行被吞 | 改完立刻跑，空值当场现形 |
| 脚本模板自己就报语法错 | 占位符写成 `<字面量>`，`<` 被当重定向 | 占位符用 `__大写下划线__`；模板也 `bash -n` 过 |
| `cd: path\npath: No such file` | `a \|\| b && c` 左结合，两段路径被拼成两行 | 用 `if X="$(...)"; then` 显式分支 |
| 死引用扫描误报真实存在的路径 | 样例目录与解析基准搞混 | 分离「样例落点」与「解析根」两个变量 |
| 中文在校验输出里乱码 | 终端编码 | 改用 ASCII 校验（`grep -c` / `od -c`） |
| 子代理越界转换 / 报告与实际不符 | 派发时没点名范围 | 显式列转换清单；越界项列入裁决表交人拍板，**不要自行回退** |
